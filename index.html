Sobre o projeto

O MoneyTrack Mini é uma aplicação web desenvolvida com foco em organização, simplicidade e facilidade de utilização.

O projeto utiliza tecnologias fundamentais do desenvolvimento web para construir uma experiência interativa e responsiva.

HTML5 CSS3 JavaScript LocalStorage
